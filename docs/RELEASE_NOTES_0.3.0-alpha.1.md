# MiVibe Remote 0.3.0-alpha.1

0.3 将已通过独立实机测试的返回、菜单和音量映射接入常驻应用，并更新托盘控制中心。当前为硬件预览候选；本文不代表新安装包已经完成实机验收或公开发布。

## 新功能

| 实体按键 | 0.3 行为 |
| --- | --- |
| 返回 `<` | 每次按下发送一次 Delete，长按不连续删除；需要启用增强按键 |
| Home | 保留每次按下发送一次 Delete，长按不连续删除 |
| 菜单 | 打开 Typeless Translate，使用右 Shift + T |
| 音量＋ | 切换侧栏顺序中的上一个 Codex 对话，仅在 Codex 前台生效 |
| 音量－ | 切换侧栏顺序中的下一个 Codex 对话，仅在 Codex 前台生效 |
| TV | 保留原始反引号输入 |

开关键仍用于 Typeless 开始/完成，麦克风键仍需按住采音，方向环与中心确认维持原来的导航和 Enter。音量键执行相邻对话切换，与鼠标侧键的访问历史后退/前进不同。

## 控制中心

- 更紧凑的 0.3 标题与设备状态条，分开展示语音连接、增强按键和真实电量。
- 保留深绿/暖橙配色、用户自有实拍图校准的遥控器插画、浅色模式和系统高对比支持。
- 返回和音量的功能说明随真实连接状态更新，未启用时明确显示“启用增强按键后可用”。
- 增加“增强按键”区域：启用、停用、重新校准及三个校准步骤；保留语音连接、音频检查、登录启动与安全退出。

## 第一次使用增强按键

1. 打开完整的 0.3 应用，双击托盘图标。
2. 点击 **启用增强按键**，在 Windows 提示中批准管理员权限。
3. 等待出现 **等待按键**，跟随高亮步骤，依次短按并松开 **返回 → 音量＋ → 音量－**。
4. 显示 **已启用** 后再使用返回与音量映射；校准过程不执行 Delete 或切换对话。

每次重新启动应用都需手动启用增强按键。登录启动只启动 MiVibe，不自动批准权限或启用增强组件。驱动宿主断开后会尝试恢复，恢复后必须重新完成三键校准。可以点击 **重新校准** 重新识别按键来源，或点击 **停用增强按键** 结束增强功能；关闭窗口仍在托盘运行，**安全退出** 结束整个应用。

## 兼容范围

- 仅针对已测 `VID 2717 / PID 32B8 / REV 00A4` 硬件族和本机观察到的同步报告路径，尚不声称覆盖其他型号或异步完成路径。
- 增强组件采用管理员辅助进程。应用只在主动启用后启动它；没有安装 HID filter 驱动，也没有新增 TV 改绑。
- 返回/音量不增加全局原生扫描码拦截。其他固件或系统版本可能需要另外处理原生事件重复，当前不能假定通用兼容。
- 原有系统级 F5/Power 扫描码映射，以及语音桥运行时电脑实体 Home/Menu 被占用的限制继续存在。
- Typeless、VB-CABLE、Codex 仍需分别安装和配置。Typeless Translate 快捷键需匹配右 Shift + T；自定义 Codex 快捷键时需匹配 Ctrl + PageUp / Ctrl + PageDown。
- TV 保持原始输入；未来若改绑，仍需解决仅抑制遥控器原生事件并保留电脑反引号的问题。

安装与操作步骤见 [Quick Start](QUICK_START.md)。
