# MiVibe Remote 0.2 发布范围

## 目标

0.2 将已经可用的 0.1 语音链路收敛为一个可以长期运行、由普通用户维护连接状态的 Windows 托盘应用。`0.2.0-alpha.1` 先作为公开源码 Preview 接受真实硬件反馈；完成本文件的全部稳定性与安装验收后，再冻结稳定版并生成安装包。

## 必须交付的四项功能

### 1. 单实例托盘前端

- 登录后只运行一个 MiVibe 托盘实例，重复启动不会产生第二套按键钩子或蓝牙会话。
- 托盘显示当前状态，并提供连接/重新连接、暂停、音频路由、开机启动和安全退出入口。
- 双击托盘打开一个极简状态窗口，而不是复杂设置中心。窗口包含一句产品简介、设备名称、连接状态、电量，以及重新连接、暂停/启动、音频检查和开机启动。
- 状态窗口用与实物一致的矢量遥控器展示每个可识别按键的当前用途，并列出 Typeless 与 Codex Voice 两条三步工作流；关闭窗口只隐藏到托盘，不退出后台服务。
- 0.1 已验证的 Typeless、Codex Voice、VB-CABLE 和 AirPods 音频链路保持不变。为释放编程常用的反引号和裸符号键，0.2 的 Voice 实体入口从 TV 迁移到菜单键；Codex 中按 `Ctrl + Alt + Numpad Multiply` 录入并保存为 `Ctrl + Alt + *`，Typeless 保持独立的裸 `Numpad Divide`。
- Home 每次新按下发送一次扩展键 `Delete`；长按产生的重复按下不会连续删除。TV 键保持原始输入，不再承担 Voice 或删除动作。
- 遥控器上带 `<` 图标的返回键及音量键在当前 Windows/固件组合下没有可用的用户态事件，0.2 明确保持暂不可用，不用猜测键码或其他实体键冒充。
- 免驱版本按系统级键值识别入口：电脑键盘实体 `Menu/Application` 与 `Home` 在常驻期间也会分别触发 Voice 与一次扩展键 `Delete`。发布说明必须披露此限制；暂停或安全退出后恢复原键行为。

#### 视觉方向

- 极简生产力工具：默认深绿黑画布、暖橙语音强调色、青绿可用状态和银色遥控器；浅色模式保留高留白与克制边框。
- 科技感集中在设备与按键指南：使用低透明度光晕、连线、状态标签和 `BLE · ATVV 16 kHz · VB-CABLE` 微型链路提示，不做满屏霓虹或复杂仪表盘。
- 保持清晰对比度、键盘可操作性、系统级字体缩放和 Windows 高对比模式；不使用持续动画或多页导航。
- 首次使用的简介由一句产品说明、遥控器映射示意和两条三步工作流组成，不增加 onboarding 向导。

### 2. 蓝牙连接/重新连接按钮

- 菜单使用明确的“连接遥控器”或“重新连接遥控器”文案。
- 用户主动点击重新连接时，先请求当前语音桥完成安全清理，再建立新会话；不强制杀死仍在清理的进程。
- 意外断开继续使用 2、5、10、30 秒封顶的自动重连；手动暂停和安全退出不会触发重连。

### 3. 电量提示

- 从标准 Battery Service `0x180F` 的 Battery Level `0x2A19` 读取 `0–100%` 电量。
- 连接成功后主动刷新；设备支持 Notify 时订阅变化，否则采用低频刷新。
- 托盘菜单和轻量状态界面显示电量。读取失败显示“未知”，不得误报为 `0%`。
- 断线时最后一次电量只能标记为“上次读取”，重新连接后再次刷新。

### 4. 开机自动启动

- 托盘提供“开机自动启动”复选项，默认关闭，由用户主动启用。
- 使用当前用户的 Windows 登录启动项，不要求管理员权限。
- 启用项绑定已安装的 0.2 可执行文件绝对路径；关闭时只移除 MiVibe 自己的值。
- 登录启动与手动启动共同受单实例保护。

## 明确不进入 0.2

- 可编辑的任意按键映射器；0.2 只展示固定映射示意，不提供编辑。
- HID filter 驱动、正式驱动签名和缺失按键修复。
- 60 秒麦克风自动无缝续段。
- 自动审批、“Allow once”宏和其他敏感动作。
- 对话列表切换和复杂主题系统。

## 发布验收

1. 托盘重复启动 10 次，系统中始终只有一个 0.2 托盘和一个语音桥。
2. 主动重新连接可以安全清理并恢复 Typeless 与 Codex Voice。
3. 关闭并重新打开 Windows 蓝牙后，自动重连成功；遥控器菜单键单次按下只触发一次 Codex Voice，Home 每次新按下只产生一次扩展键 `Delete` 且长按不连删，TV 与电脑反引号、波浪号保持原始输入。
4. 电量值与 Windows 蓝牙设备页面一致或处于合理刷新延迟内；断线、无权限和不支持 Notify 时均不会崩溃。
5. 开机启动可以启用、注销后自动运行、再次关闭并确认启动项消失。
6. 连续运行至少 30 分钟，完成多轮 Typeless 输入和 Codex Voice 问答，无粘键、重复托盘、无限日志或残留进程。
7. 安装、升级和卸载均不覆盖用户已有的无关启动项或键盘映射；卸载后不保留失效的 MiVibe 启动路径。
8. 验证电脑实体 `Menu/Application` 与 `Home` 在常驻期间分别触发 Voice 与一次扩展键 `Delete`，且暂停和安全退出后恢复原行为；将其作为 0.2 已知免驱限制写入发布说明。
9. 确认返回（`<` 图标）与音量键在当前用户态版本中明确显示为不可用，不误报已映射，也不阻塞其他按键。
