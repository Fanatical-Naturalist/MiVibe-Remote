# MiVibe Remote 0.3.0-alpha.3

返回键现在执行 **Backspace**，删除光标前的字符；Home 保留 **Delete**，删除光标后的字符。两者每次按下只执行一次，长按不重复删除。

## 按键与界面

| 按键 | 功能 |
| --- | --- |
| 返回 | Backspace，需启用增强按键 |
| Home | Delete |
| 菜单 | Typeless Translate，右 Shift + T |
| 音量＋ / − | 按 Codex 活动视图当前已加载列表切换上一项 / 下一项任务 |
| TV | 保留原始反引号输入 |
| 开关键 / 麦克风 | Typeless 开始或完成；按住麦克风说话 |

保留明暗主题控制中心、电量与增强状态、三步校准、暂停恢复，以及重复点击开始菜单图标显示现有窗口的功能。

TV 并非硬件上不能改绑：诊断已识别其原始报告。但定向抑制遥控器原生反引号、同时保留电脑键盘输入，还需单独实现。此版本不改变 TV。

## 安装与启用

先在旧版选择“安全退出”，再运行 Setup 升级。已有系统按键映射无需重新应用。开始菜单可固定 MiVibe Remote；控制中心可开启“开机自动启动”。

每次应用启动后，增强按键需主动启用、允许管理员提示，并依次短按松开 **返回 → 音量＋ → 音量－** 校准。校准期间不执行删除或切换。

活动视图按已加载列表排序，到边界停止；菜单打开或当前项不明确时跳过。普通视图使用默认任务快捷键，无需修改 Codex 配置。

## 验证与范围

alpha.2 已通过用户对菜单翻译、活动列表往返及原返回 Delete 的实测；alpha.3 改为 Backspace，其他映射保留。新验收见 [验证记录](VALIDATION_0.3.0-alpha.3.md)。

仅在已测 `VID 2717 / PID 32B8 / REV 00A4` 及本机 Codex 布局上验证。完整语音、驱动断连与其他电脑生命周期仍需继续测试。Windows 11 x64 24H2+；VB-CABLE、Typeless、Codex 分别安装。安装包未签名，以 GitHub 预发布形式提供。
