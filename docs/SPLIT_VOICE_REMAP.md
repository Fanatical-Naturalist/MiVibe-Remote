# 分离式语音控制扫描码映射

## 目标

把 Typeless 的“轻触开始/轻触结束”和小米遥控器麦克风的“按住才采音”拆给两枚实体按键：

1. 轻触开关键：开始 Typeless。
2. 按住麦克风键说话，松开停止遥控器音频。
3. 再轻触开关键：结束 Typeless 并开始转写。

## 已确认的输入

- 开关键：扩展扫描码 `E0 5E`，`VK 0xFF`；按下和松开成对，轻触不会触发睡眠、锁屏或关机。
- 麦克风键：扫描码 `00 3F`（原始 F5），按住时约每 32 ms 自动重复。
- Typeless 已确认能把 `NumpadDivide` 保存为独立语音输入快捷键。
- Typeless 已确认忽略 F13；因此 F13 可作为麦克风原始键的安静占位目标。

## 最终映射

| 来源 | 目标 | 用途 |
|---|---|---|
| 开关键 `E0 5E` | Numpad Divide `E0 35` | 轻触切换 Typeless 开始/结束 |
| F5 `00 3F` | F13 `00 64` | 避免长按麦克风触发 Typeless 快捷键提示 |

注册表二进制值：

```text
00000000000000000300000035E05EE064003F0000000000
```

该映射由 Windows 全局扫描码表实现，无法区分遥控器和电脑键盘。因此电脑实体 F5 也会变成 F13。启用、修改或撤销后均需重启 Windows。

## 启用

以管理员身份运行：

```powershell
.\tools\keyboard-remap\Enable-SplitVoiceRemap.ps1
```

脚本只允许在以下状态写入：没有现有映射、精确的旧 F5→F13 实验值、精确的旧 F5→Numpad Divide 实验值。任何其他系统映射都会被保留，脚本会拒绝覆盖。

## 查看状态

```powershell
.\tools\keyboard-remap\Get-VoiceRemapStatus.ps1
```

## 撤销

以管理员身份运行：

```powershell
.\tools\keyboard-remap\Disable-VoiceRemap.ps1
```

撤销脚本只删除项目已知的精确映射值；遇到其他值会停止。执行后重启 Windows，恢复原始开关键和 F5。

## 重启后验收

1. Typeless 中保留 `NumpadDivide` 语音输入快捷键。
2. 打开记事本并聚焦输入区域。
3. 轻触遥控器开关键，确认 Typeless 开始等待语音。
4. 按住麦克风键说一句完整的话，松开。
5. 再轻触开关键，确认 Typeless 结束并把文字写入记事本。
6. 确认长按麦克风时不再出现 Typeless 快捷键帮助层。

## 已验收的最小延迟交互

语音桥已经连接并显示 `Capture armed` 时，不需要故意等待：

1. 轻触开关键后，自然地立即按住麦克风。
2. 连续说完内容；确认最后一个字已说完再松开麦克风。
3. 松开后自然地立即轻触开关键结束 Typeless。

双探针实测自然操作时间：

- 第一次开关键松开到实体麦克风段开始：约 `165 ms`。
- 实体麦克风结束到第二次开关键按下：约 `239 ms`。
- Typeless 在第二次开关键松开后约 `2.47 s` 完成文字粘贴；这是识别处理时间，不需要用户继续等待或操作。

复杂语句“琥珀色齿轮二十六号，三只白鹭绕过月球车，校验码是八四一七，最后一个词是山竹”完整输出，数字被正常格式化为 `26`、`3`、`8417`。

程序默认 PCM 增益为 `+12 dB`。实测 WAV RMS `-36.08 dBFS`、无触顶样本，处于本设备清晰人声范围。结尾能量可能来自周围手机公放等环境声音，不能只凭非静音尾部判断截断。

注意：松开麦克风后遥控器物理隐私门会立刻停止采音。不要在松开之后继续说最后一个字；需要额外保险时，可在最后一个字之后继续按住约 `0.2–0.4 s`，但这不是桥接程序要求的固定等待。
