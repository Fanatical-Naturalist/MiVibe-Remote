# MiVibe Remote v0.1.0-prototype 冻结说明

## 版本定位

这是 2026-08-21 冻结的第一个本地可用基线，供项目作者开始日常使用和后续回归测试。它不是公开 release，暂不上传 GitHub。

源码冻结标签：`v0.1.0-prototype`。

冻结 ZIP 旁提供同名 `.sha256` 文件，可在后续开发过程中确认日常使用包没有被意外改写。

## 已通过的实体链路

### Typeless

`开关键轻触 → Typeless 开始 → 麦克风按住说话 → 松开 → 开关键轻触结束 → 正确文字`

复杂随机句、数字和不可预测尾词已经完整识别。自然操作下，开始侧约 165 ms、结束侧约 239 ms，无需人为固定等待。

### Codex Voice

`TV 轻触 → Voice 打开 → 麦克风按住说话 → 松开 → GPT 回复 → TV 轻触关闭`

快捷键、遥控器音频、VB-CABLE、Codex Voice 理解与回复均已通过。

### AirPods 共存

- 默认录音：`CABLE Output`。
- 默认通信录音：`CABLE Output`。
- 默认播放：AirPods Pro。
- 默认通信播放：AirPods Pro。
- AirPods 麦克风存在，但不是默认输入。

同一常驻会话完成 Typeless 与 Codex Voice 两段语音，共 851 包、约 12.765 秒，安全退出完整。

## 支持边界

- Windows 11 24H2/25H2 x64。
- 已配对的小米蓝牙语音遥控器，程序兼容名称 `小米蓝牙语音遥控器` 与 `MI RC`。
- .NET 9 Desktop Runtime。
- 用户独立安装的 VB-CABLE。
- 当前机器已经应用并重启过分离式键盘扫描码映射。

## 日常启动

解压冻结包后双击：

```text
MiVibe.Remote.Tray.exe
```

托盘状态变为“运行中”后即可使用。右键图标可暂停、恢复、检查音频路由或安全退出。

## 已知限制

1. TV 键与电脑键盘反引号共享 Windows 键码。托盘运行期间，实体反引号也会触发 Codex Voice；安全退出后立即恢复。
2. 蓝牙断开后需要从托盘暂停再启动，尚无自动重连。
3. 暂无开机启动和安装器。
4. 返回键与音量加减没有可用用户态事件。
5. 语音识别服务可能出现普通 ASR 偏差，例如一次把“十七”识别为“七”；这不等同于 BLE 音频丢失。

## 停用与回退

1. 先从托盘选择“安全退出”。
2. 如需撤销系统扫描码映射，以管理员身份运行：

```powershell
.\tools\keyboard-remap\Disable-VoiceRemap.ps1
```

3. 脚本修改扫描码映射后需要手动重启 Windows 才会完全生效。

项目不会自动重启，也不会自动批准权限对话框。
