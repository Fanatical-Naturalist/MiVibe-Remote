# MiVibe Remote 0.3.0-alpha.2

0.3 硬件预览版：返回键删除、菜单键启动翻译，音量键按 Codex 活动视图的实际顺序切换任务。三项已通过用户实测，同时更新控制中心界面及暂停、恢复行为。

## 按键与界面

| 按键 | 功能 |
| --- | --- |
| 返回 | 单次 Delete，长按只触发一次；需要增强按键 |
| Home | 单次 Delete |
| 菜单 | Typeless Translate，右 Shift + T |
| 音量＋ / − | 活动视图按当前已加载列表切换上一行 / 下一行任务；普通视图沿用默认任务导航。需启用增强按键且 Codex 在前台 |
| TV | 保留原始反引号输入 |
| 开关键 / 麦克风 | Typeless 开始/完成；按住麦克风采音 |

控制中心保留深绿/暖橙配色、浅色模式、真实电量、独立增强状态及三步校准。

## 修复

- 暂停与安全退出时立即撤销按键动作，组件清理期间不会继续处理新按键。
- 暂停后需先恢复连接，才能重新启用增强按键；正在退出的组件仍可继续停用。
- 按键控制器因发送失败而停止后，重新连接能够重新建立控制器。健康控制器仍独立于语音重连运行。
- 活动视图通过 Windows UI Automation 直接调用当前已加载列表相邻任务行，按眼前显示的顺序切换；到边界停止不绕回，菜单打开或当前项不明确时跳过，不自动加载更多任务。
- 普通视图保留默认 **Ctrl + PageUp / PageDown**，一次发送包含 Ctrl 和 Page 键完整按下/松开的四个事件；无需新增或修改 Codex 快捷键。
- 开始菜单与桌面快捷方式可直接打开控制中心；程序已在托盘运行时，再次打开快捷方式会显示原窗口，不会启动第二个遥控器会话。开机启动保持托盘运行。

## 使用

先安全退出旧版，再运行完整的新包。点击“启用增强按键”并响应 Windows 管理员提示；依次短按并松开 **返回 → 音量＋ → 音量－**，显示“已启用”后即可使用。每次启动需主动启用；驱动重连后需要重新校准。关闭窗口仍在托盘运行，“安全退出”结束全部组件。

活动视图按当前已加载列表上下切换；请先关闭任务菜单。到首尾停止，不会绕回，也不跨越尚未加载的任务。普通视图沿用默认快捷键；若右侧面板优先切换标签，请先点击输入框再按音量键。无需新增 Codex 快捷键，也不使用鼠标侧键的访问历史顺序。更完整的行为与排查见 [Quick Start](QUICK_START.md)。

## 验证范围

独立实机探针曾验证返回、菜单和音量动作。alpha.1 完整主程序已成功连接语音、读取设备电量，并由用户完成三键校准；用户随后确认返回 Delete、菜单 Translate 正常。音量在点击输入框后能够切换任务，但顺序与当前活动视图不符，因此 alpha.2 改为在活动视图直接选择列表相邻行。增强组件的独立进程连接/安全退出及自动测试已通过。

alpha.2 完整主程序已由用户确认：音量－按活动列表下移一项、音量＋回到原任务，返回 Delete 与菜单 Translate 也正常。普通快捷键 27 项离线回归、19 条协议消息检查及 6 种界面控制状态检查通过。完整语音输入、翻译输出、驱动断连、暂停恢复及其他电脑的安装生命周期仍需进一步验证。

当前只针对已测 `VID 2717 / PID 32B8 / REV 00A4` 的同步报告路径；没有增加全局返回/音量拦截，也没有改变原有 Power/F5 系统映射。电脑实体 Home/Menu 在运行期间仍被占用。TV 保持原始输入。VB-CABLE、Typeless 和 Codex 需分别安装。
