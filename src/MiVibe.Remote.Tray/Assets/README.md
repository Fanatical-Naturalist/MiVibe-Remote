# Product image status

`UserOwnedRemote2ProIllustration.png` is the application artwork. It was derived
from a user-owned reference photograph to preserve the remote's geometry,
button layout, and silver/black material language. The result is a clean,
front-facing industrial-design illustration with all Xiaomi and NFC branding
removed. It is intended for the MiVibe Remote UI and User Guide.

The following files are local review intermediates only and are intentionally
ignored by Git:

- `XiaomiRemote2ProOfficialPreview.jpg` — Xiaomi product-page preview; do not
  redistribute without permission.
- `UserOwnedRemote2ProCutout.png` — discarded photo-style generation with a
  non-transparent checkerboard background.
